# Load unpacked

1. From the repo root, run `npm install` then `npm run build`.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Choose Load unpacked and select the `dist/` folder.
5. Open YouTube Music or Spotify Web and press play. The Floater opens on top of every app.
6. If playback started without your click, a small Now Bar pill appears bottom-right of the page. Click it.
7. Click the toolbar icon for the Panel: open on play, Dots or Glyphs, which Scenes run, default layout.

Inside the Floater: prev / play / next drive the music page. The grid button skips to the next Scene, the dash collapses to a pill, then to an icon. Click the icon to expand.

Chrome 116 or newer on desktop. Document Picture-in-Picture is required.
