# Load unpacked

1. From the repo root, run `pnpm install` then `pnpm build`.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Choose Load unpacked and select the `dist/` folder.
5. Open YouTube Music or Spotify Web and play a track.
6. Click the Now Bar toolbar icon. The Owner opens. Click the glass pill to collapse. Click the Scene to skip.

Chrome 116 or newer. Document Picture-in-Picture is required for the Floater.
